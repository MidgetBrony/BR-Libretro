# BR-Libretro 0.6.25

- Builds ROM console tabs from platform profiles that have a compatible installed or explicitly mapped core.
- Multiple cores for the same platform continue to share one console tab and appear as core choices.
- Installing a new core explains that BOXROOM must restart before console tabs are rebuilt.
- Keeps platform profiles authoritative for folders, IGDB IDs, discovery rules, and physical-media presentation.
- Includes the simplified ROM manager and NES neighbour-label fix from 0.6.24.
