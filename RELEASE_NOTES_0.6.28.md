# BR-Libretro 0.6.28

- Adds and removes compatible console tabs immediately after in-game core installation or uninstallation.
- Keeps a console tab while another compatible core remains and preserves a surviving selected console.
- Includes safe core uninstallation while retaining ROMs, saves, BIOS files, mappings and core choices.
- Corrects the MelonLoader version banner and requires BR-MediaAPI 1.1.21 for consistent BoxMate version detection.
