# BR-Libretro 0.4.12

BR-Libretro is experimental. Back up important BOXROOM room saves before testing and supply your own legal libretro cores, BIOS files, and game content.

## Included

- Runs supported libretro cores inside BOXROOM without launching RetroArch.
- Uses Boxroom-TV's shared display ownership so videos and emulators do not overwrite each other.
- Provides configurable keyboard and gamepad bindings through ModsPanel.
- Gives NES games using Mesen, FCEUmm, or Nestopia a physical cartridge model with BOXROOM cover art.
- Preserves normal shelf, pickup, inspection, loose-placement, FreePlace rotation, resizing, and save behavior through BR-MediaAPI.

## Important

- No emulator cores, BIOS files, ROMs, or copyrighted game content are included.
- Live behavior depends on the supplied core and content. This release was built and package-verified, but every core/game combination is not guaranteed.
