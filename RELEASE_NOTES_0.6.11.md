# BR-Libretro 0.6.11

- Presents Game Boy, Game Boy Color, and Game Boy Advance ROMs as procedural retail boxes.
- Uses the supplied platform-frame artwork without requiring new GLB models.
- Fits existing ROM cover artwork into each frame's transparent artwork opening.
- Samples the cover palette for the box body and uses platform-specific box proportions.
- Retains BOXROOM's native shelf layout anchor and existing ROM media lifecycle.
