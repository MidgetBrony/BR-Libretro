# BR-Libretro 0.4.13

- Adds an in-game core manager under BR-Libretro's mod settings.
- Browse, search, install, update, and inspect official Windows x64 libretro cores.
- Manage file-type mappings and restore the recommended defaults from the same menu.
- Requires ModsPanel 2.6.3 so closing the manager correctly returns control to BOXROOM's settings menu.

BR-Libretro remains experimental. Restart BOXROOM after installing or updating.
