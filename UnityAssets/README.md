# BR-Libretro UnityAssets

This folder is the editable Unity 6000 asset handoff, matching the pattern used by BR-MediaAPI and BR-BookSystem. Use it for native-style overlays, screen materials, controller prompts and optional prefabs. Do not embed cores, BIOS files, ROMs, or the libretro execution loop in an AssetBundle.

The first runtime version uses the existing TV screen material directly and therefore does not require a compiled bundle yet.
