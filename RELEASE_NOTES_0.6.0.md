# BR-Libretro 0.6.0

- Adds optional Studio-style IGDB metadata matching from the ROM console tabs.
- Filters searches by console, cleans common ROM filename tags and supports manual review.
- Adds bulk matching for unique exact-title results while leaving ambiguous games untouched.
- Persists IGDB IDs, canonical titles, summaries, dates, developers, publishers and genres in the stable ROM registry.
- Downloads and caches IGDB cover artwork against the ROM media ID for cartridge and disc presentation.
- Keeps ROM discovery and launching fully offline when IGDB is not configured.
- Requires ModsPanel 2.7.5 for masked Client Secret entry.

Validation: Release build; live IGDB credential and matching acceptance pending.
