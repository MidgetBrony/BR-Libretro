# BR-Libretro 0.4.15

- Adds a physical NTSC-style SNES cartridge for games using the Snes9x core.
- Uses a dedicated 92:43 `label.png` when available, with ordinary BOXROOM box art as the fallback.
- Adds a connected black wraparound label with the game name in green on the cartridge end.
- Preserves the cartridge orientation across face-out, spine-out and face-up shelf placements and placement previews.
- Recognises existing Snes9x launch commands even when their previously configured core DLL path no longer exists.
- Includes attribution and licensing details for the modified CC BY-NC 4.0 cartridge model; this release is for noncommercial distribution only.

BR-Libretro remains experimental. Restart BOXROOM after installing or updating.
